# MAGHRABY STORE

نسخة أولية Offline-First لنظام إدارة المحل.

## التشغيل
- ارفع الملفات كما هي إلى GitHub Pages.
- افتح الموقع مرة واحدة بالإنترنت حتى يتم تحميل ملفات التطبيق.
- بعد ذلك يمكن للتطبيق العمل بدون إنترنت على نفس الجهاز.
- البيانات محفوظة محليًا في المتصفح باستخدام IndexedDB.

## اللوجو
استبدل الملف:
`public/logo.svg`
بلوجو المحل الحقيقي مع الحفاظ على نفس الاسم، أو عدّل مساره في `index.html` و `manifest.webmanifest`.

> مهم: GitHub Pages لا يوفر قاعدة بيانات مشتركة بين الأجهزة. هذه النسخة تحفظ البيانات محليًا على كل جهاز. يمكن إضافة مزامنة لاحقًا.
