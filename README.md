# MAGHRABY STORE PRO — V6 Fresh

نسخة محلية Offline-First مخصصة لإدارة MAGHRABY STORE، تبدأ بقاعدة بيانات فارغة تمامًا.

## التشغيل
1. فك الضغط.
2. افتح `index.html` في Chrome أو Edge.
3. لو أردت تشغيل PWA/Service Worker بشكل كامل، شغّل المجلد عبر Local Server؛ لكن البيانات نفسها تعمل داخل IndexedDB على الجهاز.

## مهم
- هذه النسخة تستخدم قاعدة بيانات جديدة: `MAGHRABY_STORE_FRESH_V6`.
- لا تحتوي على منتجات أو عملاء أو معاملات تجريبية.
- الشعار الرسمي موجود في `public/logo.png`.
- البيانات محفوظة محليًا داخل المتصفح.
- استخدم النسخة الاحتياطية بانتظام من الإعدادات.

## أهم ما تم تطويره
- هوية UI داكنة احترافية مستوحاة من ألوان الشعار: كحلي، أزرق كهربائي، سماوي، أخضر.
- POS أسرع مع عميل + حساب دفع + خصم + ملاحظات.
- الدرج والمحفظة وInstaPay كأرصدة مستقلة مع رصيد بداية وإقفال يوم.
- تحويل بين الحسابات بدون احتسابه دخلًا أو خرجًا للمحل.
- صيانة بمراحل: استلام/فحص → بانتظار العميل → تم الإصلاح / رفض → تم التسليم.
- WhatsApp للعميل برسالة جاهزة.
- تقارير أسبوعية وشهرية وسنوية مع فصل التحويلات عن دخل/خرج التشغيل.
- منتجات وخدمات منفصلة؛ الخدمة لا تستهلك المخزون.
- Backup / Restore محلي.
