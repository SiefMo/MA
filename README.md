# MAGHRABY STORE — PRO V3

هذه النسخة ليست مجرد تغيير ألوان؛ تم إعادة تنظيم النظام حول طريقة شغل المحل:

- Dashboard يومية لمتابعة الدخل والخارج والربح التقريبي والأجهزة المعلقة.
- Cashier / Sales: سلة، كميات، خصومات، ملاحظات، خصم منفصل، وفاتورة قابلة للطباعة.
- Repairs Pipeline: تحت الفحص / جاهز / بانتظار العميل / تم التسليم + عمر الجهاز بالأيام.
- Inventory: سعر شراء، سعر بيع، هامش، كمية، حد أدنى، صورة.
- Purchases: شراء بضاعة يزيد المخزون ويخرج الفلوس من الخزنة.
- Expenses: تشغيل المحل مثل إيجار، كهرباء، مياه، تنظيف ومعطر.
- Staff: الفنيون والموظفون + السلف كحركة خروج من الخزنة.
- Needs: اقتراح الأصناف التي وصلت للحد الأدنى.
- Reports: مبيعات، تكلفة البضاعة، مصروفات، دخل الصيانة، ربح تقريبي، خصومات، فرق الدرج.
- Daily Close: عد الفلوس الفعلية ومقارنتها بالمتوقع.
- Backup/Restore: JSON.
- IndexedDB + Service Worker: حفظ محلي والعمل بدون إنترنت بعد تحميل الموقع أول مرة.

## اللوجو
استبدل `public/logo.svg` بلوجو المحل الحقيقي مع الحفاظ على نفس الاسم.

## مهم بخصوص GitHub Pages
GitHub يستضيف ملفات الموقع، لكنه ليس قاعدة بيانات للمحل.
البيانات في هذه النسخة محفوظة محليًا على الجهاز/المتصفح. لذلك لو فتحت الموقع من جهاز آخر لن تنتقل بيانات الجهاز الأول تلقائيًا. استخدم Backup/Restore لنقلها، أو نضيف لاحقًا قاعدة بيانات سحابية اختيارية لو احتجت مشاركة البيانات بين أكثر من جهاز.

## النشر
ارفع محتويات المشروع إلى repository ثم فعّل GitHub Pages من Settings → Pages → Deploy from branch → main/root.
