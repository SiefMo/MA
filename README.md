# MAGHRABY STORE V9 FINAL

نسخة Local / Offline-first نهائية لمحل MAGHRABY STORE.

- قاعدة بيانات جديدة وفارغة: MAGHRABY_STORE_FRESH_FINAL
- لا توجد بيانات تجريبية أو منتجات مسبقة.
- اللوجو المرفق هو الصورة التي زودت بها المشروع، محفوظة بصيغة PNG.
- واجهة جديدة بهوية مستوحاة مباشرة من ألوان اللوجو.
- الحفاظ على منطق المبيعات، المخزون، الصيانة، WhatsApp، الدرج، المحفظة، InstaPay، إقفال اليوم، التحويلات والتقارير.
- Service Worker جديد مع تنظيف للكاش القديم ونسخ versioned للملفات حتى لا تظهر واجهة قديمة.


## حفظ البيانات
المعاملات لا تنتهي تلقائيًا بعد سنة معينة؛ تبقى في IndexedDB محليًا حتى حذف بيانات الموقع/المتصفح. يوصى بعمل نسخة احتياطية شهرية ونسخة سنوية خارج الجهاز.
