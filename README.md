# MAGHRABY STORE V2
نسخة واجهة احترافية Offline-First.

## اللوجو
ضع لوجو المحل الحقيقي في:
`public/logo.svg`
بنفس الاسم.

## أهم ما تم تحسينه
- واجهة احترافية وهوية ألوان أحدث.
- السلة بها ملاحظات.
- المنتجات تدعم صورة فعلية.
- المشتريات: اختيار منتج + كمية + تكلفة، وتزيد المخزون تلقائيًا وتسجل الخرج.
- مصروفات المحل تشمل الاستهلاك مثل المعطر، بينما البضاعة التي ستباع تسجل من المشتريات.
- حفظ محلي عبر IndexedDB، ويستمر بعد إغلاق الصفحة/الجهاز على نفس المتصفح والجهاز.
- تقرير يومي وإقفال اليوم مع عدّ فلوس الدرج وحساب الفرق.
- التاريخ والوقت ظاهرين باستمرار.
- نسخة احتياطية واستيراد.
