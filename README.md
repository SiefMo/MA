# MAGHRABY STORE — Final Complete

نسخة نهائية محلية (Offline-first) لإدارة MAGHRABY STORE، مبنية على النسخة التي تم اختبارها عمليًا، مع الحفاظ على الميكانيزم السابق وإضافة الإصلاحات المطلوبة.

## أهم ما تم تثبيته
- POS: بيع، سلة، حذف عنصر، تفريغ السلة، خصم، كود خصم، عميل، طرق دفع.
- حفظ الفاتورة داخل Transaction واحدة مع تفريغ السلة بعد النجاح فقط.
- المخزون: إضافة/تعديل/تعطيل/حذف، باركود، حركة مخزون، مشتريات، مرتجعات، تكلفة وربح.
- الصيانة: PS5/PS4/Xbox/**دراع** وغيرها، تاريخ ووقت الاستلام، Serial، ملحقات، فني، موعد تسليم، أنواع وأسعار الصيانة، قطع غيار مرتبطة بالمخزون، QR، WhatsApp، وتحويل التسليم إلى الكاشير.
- الدرج + المحفظة الإلكترونية + InstaPay: أرصدة مستقلة، دخل/خرج، تحويلات داخلية، وإقفال يوم مع رصيد مرحّل لليوم التالي.
- التقارير: يومي/أسبوعي/شهري/سنوي، دخل/خرج/صافي، حسب الحساب، خصومات، مرتجعات، تكلفة قطع الغيار، وطباعة/حفظ PDF من المتصفح.
- Backup خارجي + حفظ احتياطي يومي داخلي لآخر 30 يومًا، وRestore يستبدل البيانات الحالية بالكامل بعد التأكيد.
- حسابات العملاء منفصلة عن الحسابات المالية.
- واجهة عربية محسّنة وهوية مبنية على اللوجو الرسمي PNG.

## البيانات
قاعدة البيانات IndexedDB محلية ولا يوجد حذف تلقائي للمعاملات بعد سنة. الاحتفاظ لسنوات متعددة ممكن طالما بيانات الموقع موجودة، ويجب الاحتفاظ بنسخ Backup خارج الجهاز.
